## 🌟 TỔNG QUAN DỰ ÁN & ĐIỂM NHẤN CỐT LÕI

Dự án được định vị là một siêu phẩm **Dual-Gameplay Hybrid** vận hành mượt mà 100% trên nền tảng Web Browser (PC Web & Mobile Web) không cần cài đặt:

1. **Gameplay 1 - Cày Cuốc Dã Ngoại (2.5D Isometric 8 Hướng):**
   * Người chơi nhập vai Nhân vật chính (Kẻ Thức Tỉnh Song Tu) chu du thế giới mở 20 Channels.
   * Cày quái, săn Boss dã ngoại, **khóa bảo vệ rương 30s & cướp đồ tự do**, lò rèn +15 phát sáng hào quang thần khí.
   * Nền kinh tế Chợ Trời tự do: **Quy tắc Unbound 100% đồ Boss**, dựng sạp bán hàng và trade trực tiếp P2P.
   * Chiến trường PK đẫm máu: 3 chế độ Cờ (Trắng, Đỏ, Bang), Tên Đỏ bị hạ gục rơi 10% vàng và 50% nguy cơ rớt đồ đang mặc.

2. **Gameplay 2 - Đội Hình Chiến Thuật Gacha (Spine 2D Side-View):**
   * Hệ thống **Đài Triệu Hoán Thái Hư**: Gacha chiêu mộ các Anh Linh thần thoại phương Đông & phương Tây (Khung phẩm R, SR, SSR, UR).
   * Đồ họa **Spine 2D chuyển động 60 FPS mượt mà**, visual mãn nhãn với góc nhìn ngang cận cảnh, không bị giới hạn bởi góc isometric.
   * Chiến trường Auto-Battler 5v5: Đầy thanh nộ khí 1000 điểm xả Tuyệt Kỹ Tối Thượng (Ultimate Cut-In).
   * Phụ bản đa dạng: Tháp Hư Không 100 tầng, Đấu Trường Xếp Hạng Spine Arena, Viễn Chinh Roguelike, Săn Cổ Thần 5v1.

3. **Cầu Nối Liên Thông (Dual-Loop Bridge):**
   * **Duyên Phận Bộ Sưu Tập:** Sở hữu tướng gacha tự động buff % chỉ số vĩnh viễn cho Nhân vật chính dã ngoại.
   * **Kỹ Năng Trợ Chiến (Striker Call):** Cài đặt tướng Spine làm Hộ Vệ dã ngoại. Bấm phím nóng để gọi tướng đáp xuống giáng đòn Tuyệt Kỹ quét sạch quái vật xung quanh trong 2.5 giây.
   * **Tuần Hoàn Kinh Tế:** Cày quái ngoài map nhặt vé gacha & đan dược nuôi tướng; Đánh phụ bản tướng nhặt Sách Phép Mythic & Đá Cường Hóa cho nhân vật chính.

4. **Trục Tu Tiên 9 Đại Cảnh Giới & Rủi Ro Lôi Kiếp (Cap Level 150):**
   * Thay vì chỉ có Level đơn điệu, người chơi đột phá qua **9 Đại Cảnh Giới**: **Luyện Khí ➔ Trúc Cơ ➔ Kim Đan ➔ Nguyên Anh ➔ Hóa Thần ➔ Luyện Hư ➔ Hợp Thể ➔ Đại Thừa ➔ Độ Kiếp Phi Thăng**.
   * Mỗi cảnh giới gồm 4 Tiểu Cảnh Giới (Sơ, Trung, Hậu, Đại Viên Mãn). Mốc Viên Mãn bị **Nghẽn Cảnh Giới** bắt buộc phải Độ Kiếp.
   * **Rủi Ro Lôi Kiếp:** Sấm sét giáng xuống rút % máu thật. Nếu ngã gục trong lôi kiếp sẽ bị **tụt 20% tu vi**, cần dùng Đan Dược hộ kiếp và nhờ đồng đội Bang Hội đứng "Hộ Pháp"!

## 🚀 HƯỚNG DẪN KHỞI ĐỘNG NHANH BẢN PROTOTYPE

### Cách 1: Bấm trực tiếp file tiện ích
* Nhấp đúp chuột vào file **`run-dev.bat`** tại thư mục gốc của dự án. Hệ thống sẽ tự động khởi chạy đồng thời Client và Server.

### Cách 2: Chạy bằng Terminal / Command Line
1. Cài đặt các gói thư viện:
   ```bash
   npm install
   ```
2. Khởi chạy đồng thời cả Server và Client:
   ```bash
   npm run dev
   ```
   * **Web Game Client:** `http://localhost:3000` (hoặc `http://<IP-máy-bạn>:3000` để điện thoại trong cùng mạng Wi-Fi vào chơi thử)
   * **Multiplayer Server:** `ws://localhost:2567` (cổng 2567)

## 🎮 TÍNH NĂNG ĐÃ HOÀN THIỆN TRONG BẢN PROTOTYPE

1. **Bản đồ 2.5D Isometric Diamond Grid (64x32 px):** Lưới ô chuẩn Diamond, thuật toán sắp xếp chiều sâu Z-Depth Sorting chống lỗi đè hình.
2. **Nhân vật & Hoạt ảnh 8 Hướng (Diablo/Flare style):** Đầy đủ 8 góc nhìn la bàn (`S`, `SW`, `W`, `NW`, `N`, `NE`, `E`, `SE`), 2 chuỗi hoạt ảnh `Idle` và `Walk`.
3. **Cơ chế điều khiển Hybrid (PC & Mobile Web):** Click chuột di chuyển / Phím WASD trên PC + Virtual Joystick cảm ứng trên Smartphone.
4. **Đồng bộ Multiplayer thời gian thực (WebSocket 20Hz):** Server phát sóng đồng bộ trạng thái 20 lần/giây, Linear Interpolation giúp di chuyển siêu mượt 60 FPS.
5. **HUD & Hệ thống Chat dã ngoại:** Hiển thị tọa độ, Hướng quay, Ping ms, FPS, Số người Online + Khung chat trực tiếp gõ Enter gửi tin nhắn toàn phòng.
6. **Màn Hình Load Game Sử Thi (Cinematic Preload Scene):** Logo game `title_bg` vương miện gai, thanh tiến trình 5 giai đoạn, tự động co giãn đa màn hình.
7. **Bù Nhìn Quái Vật Skeleton & Action Hotbar:** Chém quái giật lùi kèm Damage Popup Floating Text, thanh phím tắt 4 ô dưới đáy màn hình.

## 🌐 HƯỚNG DẪN HOST ONLINE CHO CỘNG ĐỒNG TEST NGAY

### Cách 1: Dùng Cloudflare Tunnel / ngrok (Chạy trực tiếp từ máy cá nhân trong 1 phút)
1. Mở cổng web client:
   ```bash
   ngrok http 3000
   ```
2. Gửi link `https://xxxx.ngrok-free.app` cho bạn bè hoặc người xem vào test ngay trên điện thoại hoặc máy tính!

### Cách 2: Deploy lên Vercel + Render (Miễn phí 100%, link vĩnh viễn)
1. **Frontend:** Kết nối GitHub repo với **Vercel** (thư mục root: `client/`, build command: `npm run build`, output: `dist`).
2. **Backend:** Deploy thư mục `server/` lên **Render.com** (Web Service Node.js).
3. Trong `client/src/network/NetworkManager.ts`, trỏ URL WebSocket về link wss của Render.
